🖥️ PART 1 — 기술 세팅 (RTX 50 + 1440p 144Hz)

목표: 그래픽 품질 최대 + 프레임 144 안정적 확보 + 게임비서(G-Assist) 활용

Phase 1. NVIDIA App 설치 및 드라이버 세팅

1-1. NVIDIA App 다운로드

  • 공식 사이트: https://www.nvidia.com/en-us/software/nvidia-app/
  • 기존에 GeForce Experience가 있다면 NVIDIA App 설치 시 자동으로 마이그레이션 됨
  • 설치 후 NVIDIA 계정 로그인 (선택, 안 해도 대부분 기능 사용 가능)

1-2. 드라이버 업데이트

  1. NVIDIA App 실행 → 좌측 메뉴 Drivers 탭
  2. Game Ready Driver 선택 (Studio Driver 아님)
  3. Game Ready: 신작 게임 출시일에 맞춰 최적화·버그픽스 빠르게 반영 → 게이밍 우선
  4. Studio: Blender·Maya·DaVinci Resolve 안정성 위주 → 나중에 클릭 한 번으로 전환 가능
  5. 최신 버전 다운로드 → Express Installation (깔끔 설치)
  6. 설치 완료 후 PC 재부팅

1-3. 시스템 정보 확인

  • NVIDIA App 우측 상단 톱니바퀴 → System 탭에서 GPU/VRAM/드라이버 버전 확인
  • VRAM 6GB 이상이면 G-Assist 사용 가능 (RTX 50 시리즈는 무조건 충족)

Phase 2. 게임비서 (Project G-Assist) 활성화

2-1. G-Assist 설치

  1. NVIDIA App → Discover 또는 Home 화면에서 G-Assist 카드 찾기
  2. Install 클릭 → AI 모델 다운로드 (수 GB)
  3. 설치 완료 후 단축키 확인 (기본: Alt + G)

2-2. 첫 실행 및 권한 설정

  1. Alt + G 눌러서 G-Assist 호출
  2. 마이크 사용 권한 허용 (음성 명령 쓸 거면)
  3. 설정에서 언어 확인 (한국어 명령 지원 여부 확인 — 영어가 더 안정적)

2-3. 자주 쓰는 명령어 (영어 권장)

  • Spotify 플러그인: 음성으로 음악 제어

  • NVIDIA 색상 설정: 디지털 바이브런스 60% (취향)
  • RTX HDR: 모니터가 HDR 지원하면 NVIDIA App에서 활성화 권장

Phase 5. G-Assist로 최종 검증

게임 켜둔 상태에서:

  1. Alt + G → "Show FPS, GPU temp, GPU usage, CPU usage as overlay"
  2. 평소 플레이 패턴(전투, 이동, 컷씬)으로 10~20분 플레이
  3. 다음 지표 체크
  4. FPS: 목표 144 근처 안정
  5. GPU 온도: 75~80℃ 이하 (이상이면 케이스 쿨링 점검)
  6. GPU 사용률: 95~99% (낮으면 CPU 병목 의심)
  7. VRAM 사용량: 카드 용량의 90% 미만
  8. 문제 있으면 G-Assist에게 "Why is my FPS dropping in combat?" 같이 물어보기

Phase 6. 컨트롤러 세팅 — Razer Wolverine V3 Pro 8K PC Wireless

붉은사막은 패드 기준으로 설계된 게임이라 PC에서도 패드가 표준. 키보드는 입력이 많아 외우기 어렵고, 말 타기/내리기 키 분리, 공격 오작동, Shift 질주 중 Windows 고정키(Sticky Keys) 팝업 문제가 있음. 마우스가 유리한 건 활/총 정밀 조준뿐(에임 보조로 패드도 충분).

⚠️ 모델 구분: 보유 모델은 "8K PC" 버전 = PC 전용(Xbox 비호환). 설정 앱은 Razer Synapse 4. Xbox 버전용 "Razer Controller Setup for Xbox" 앱에서는 인식되지 않음 — 설치했다면 삭제해도 됨.

  • Windows/Steam에서 Xbox 컨트롤러(XInput)로 인식 → 붉은사막 UI에 Xbox 버튼 아이콘 표시. 게임 실행 전 패드를 먼저 연결.
  • Steam → 설정 → 컨트롤러 → Xbox 컨트롤러용 Steam 입력은 끔. 켜면 입력 한 단계 더 거쳐 반응이 늦어지고 Synapse 매핑과 충돌 가능.

6-2. 후면 버튼 리매핑 (Synapse 4, 총 6개: 후면 4 + 클로 그립 범퍼 2)

  1. Razer 홈페이지에서 Synapse 4 설치 → 패드 유선 연결 → 장치 목록에 Wolverine V3 Pro 8K 표시 확인(안 뜨면 동글 빼고 유선만, Synapse 재시작).
  2. 장치 클릭 → 사용자 지정(Customize) 탭 → 후면 버튼/클로 범퍼 각각 클릭 → 게임패드 버튼에서 A/B/X/Y/D-패드 선택 (키보드 키도 배정 가능하지만 붉은사막은 패드 버튼으로).
  3. 온보드 프로필에 저장(최대 4개) → 패드 내부에 저장되어 Synapse를 꺼도, 다른 PC에서도 유지. 붉은사막 전용 프로필 1개 만들어 두기.
  4. 붉은사막 인게임에서는 패드 버튼 재배치가 안 되므로 Synapse 쪽에서 리매핑이 정답.

6-3. 트리거 / 스틱 / 폴링

  • Pro HyperTriggers: 후면 스위치로 마우스 클릭식(즉발) ↔ 아날로그 전환. 붉은사막은 아날로그 유지 권장 — 활 차징·말 속도 조절이 아날로그 값을 씀. 즉발 모드는 RT 강공격 반응은 빨라지지만 활 조작이 어색해짐.
  • TMR 스틱(드리프트 없음) → Synapse에서 데드존 최소, 인게임 카메라 감도 6~7, 조준 4~5, 카메라 가속 낮음. 스틱 캡은 카메라(RS)는 낮은 돔형(속도), 이동(LS)은 취향.
  • 폴링 레이트: 기본 8000Hz. 붉은사막에서 미세 끊김·CPU 점유 상승이 보이면 Synapse에서 1000Hz로 낮추기 — 액션 RPG에서 8K 이득은 체감 거의 없음.

거점 어비스 표석 수리 (거점 직행 개방)

거점 동쪽 가시덤불 뒤에 미완성 표석이 있음. 수리하면 지도에서 거점으로 바로 이동 가능.

순서내용
선행 조건챕터 4 진입 · 뻐꾸기 무쇠솥(Q7 보상) · 집중 장타(Focused Force Palm) ('금지된 지식' 퀘스트에서 획득)
1거점 동쪽 가시덤불을 빛 반사로 태워서 제거 → 미완성 표석 발견
2에르난드 성 북동쪽 카린 채석장으로 이동 → 마르니 채석 기계 처치 → 크레인으로 지하 동굴 진입
3동굴 안 포탑 파괴 → 집중 장타로 특수 벽 부수기 → 어비스 운송 장치 획득 후 거점으로 운반
4표석 받침대에 장치 올리고 공중에서 장타로 내리찍어 고정 → 활성화
  • 카린 채석장 전투는 로버츠 가문 의뢰 '흔들리는 영지' 3단계와 겹침 — 난이도 높음(양팔이 노랗게 빛날 때 빛 반사로 그로기 후 딜). 점령도 0%까지 요구되면 폭발통·회전 가르기로 건물 기둥 파괴
수리 전 임시 루트
  1. 지도 열어 늑대 언덕에서 가장 가까운 파란 아이콘으로 이동 (에르난드 흔적은 성 길목·킬덴 공방·포로린 마을 근처에 몰려 있음)
  2. 도착 후 말 호출(Z) 해서 거점까지 이동. 말 탄 채로 동료 따라가기면 자동이동 됨
  3. 새 지역 갈 때마다 눈에 띄는 흔적은 일단 밟아 켜두기 — 나중 이동 부담이 크게 줄어듦

Q9. 별의 탑 — 정상으로 올라가는 장치 가동 (챕터 4 · 스콜라스툴)

상황: Day 36, 스콜라스툴 / 별의 탑 1층. 목표 "탑 정상으로 이동할 방법 찾기 / 정상으로 올라가는 장치를 가동하시오."중앙 장치 앞에서 상호작용하면 "작동시키기 위한 무언가가 필요합니다." 메시지 + 빈 슬롯에 문양이 새겨진 돌 — E 끼워 넣기 프롬프트만 뜸.

탑 진입 자체가 안 되면: 지하 건물로 들어가지 말고 식당에서 바깥 계단으로 나가면 탑으로 바로 연결됨.

9-1. 문양이 새겨진 돌(큐브) 3개 모으기
  • 장치가 있는 홀의 좌우 양 끝 방으로 각각 들어감
  • 방 안의 문/기둥을 지정타로 밀어서 큐브(문양이 새겨진 돌)를 획득 — 총 3개 필요
  • 중요: 큐브를 주운 방의 벽화(문양 벽 부조)를 꼭 확인할 것. 어떤 문양이 어느 높이·어느 자리에 와야 하는지가 벽화에 그려져 있음
9-2. 장치에 끼우고 가동
  1. 큐브 3개를 중앙 장치 아래 슬롯에 E로 끼워 넣기 (3개 다 채워야 활성화됨 — 1~2개만으로는 "무언가가 필요합니다" 계속 뜸)
  2. 3개가 다 들어가면 장치 활성화 → 승강 구조물이 위로 뜸
9-3. 높이 맞추기 (여기서 대부분 막힘)
  • 큐브를 끼우는 것만으로는 안 끝남. 높이 정렬이 진짜 퍼즐
  • 활성화된 문양(장치)에 매달리기로 매달려서, 양쪽 사이드 벽의 문양들과 높이를 똑같이 맞추면 됨
  • 장치가 맨 아래에 있을 때 지정타(공중 장타)로 내리찍어 위치를 한 칸씩 올림
  • 세 문양의 높이가 벽화와 전부 일치하면 승강기 작동 → 정상 이동
9-4. 요약 순서
순서할 일
1좌우 방 진입 → 문/기둥 지정타로 밀기 → 큐브 3개 획득
2방마다 벽화 문양 배치 기억
3중앙 장치 슬롯에 큐브 3개 전부 끼우기
4매달리기 + 지정타로 각 문양 높이를 벽화대로 정렬
5승강기 작동 → 탑 정상

Q10. 금욕의 성소 정화 (지혜의 마녀 라인 · 서키스 영지)

상황: Day 36, 서키스 영지 / 유니콘의 절벽 부근. 퀘스트 "금욕의 성소 — 성소 주변의 적 처치하기".

선행 조건: 지혜의 마녀를 먼저 만나야 성소 정화가 가능. (Q6의 "마녀 라인은 챕터 5 이후" 메모는 정정 — 마녀를 만난 시점부터 성소 정화 개별 진행 가능)

10-1. 난이도 — 지금 가도 되나?
  • 금욕의 성소에는 보스가 없다. 안툼브라 교단 잡몹 + 퍼즐 구성
  • 지혜의 마녀 성소 4곳(금욕 / 회개 / 축복 / 면죄) 중 면죄의 성소만 고난이도 — 보스 안툼브라의 검(스펙 높고 패턴 까다로움)
  • 챕터 4(별의 탑) 진행 중이면 이 성소는 한참 뒤쪽 난이도 → 무리 아님
  • 붉은사막은 레벨 수치보다 담금질 단계가 실전력. 무기 · 장갑 · 신발 담금질 2~3회면 여유

실제 위험 요소는 몹 숫자와 원거리 궁수

  • 성소가 점령지 취급 → 주변 교단 전부 처치해야 다음 단계 진행
  • 원거리 몹이 제일 성가심 → 활로 궁수부터 끊기
  • 좁은 통로 · 문간으로 유인해서 다수에게 둘러싸이지 않게
  • 음식 넉넉히 (기력·회복)
10-2. 정화 퍼즐 상세 (적 처치 후)

핵심 준비물 3개 — 기둥 동력핵 1 + 기둥 조각 2. 전부 모아서 성소 중앙에 조립하면 정화.

① 기둥 동력핵

  • 위치: 옆 건물 계단에 끼어 있음 / 인근 바닥이 깨진 공간
  • 계단 쪽으로 돌아 나올 수도 있지만, 깨진 바닥 구멍 위쪽에 동력핵을 올려두고 회수하는 쪽이 훨씬 편함

② 기둥 조각 1 — 철창 속 (메모리)

  • 철창 안에 숨겨져 있음
  • 빛 모으기(Ctrl+좌클릭 유지)로 덩굴을 태우고 → 섭리의 힘(당기기) 으로 끌어와 회수
  • 가마솥에서 메모리를 꺼내는 연출이 이어짐

③ 기둥 조각 2 — 가시 덩굴 첨탑

  • 가시 덩굴이 있는 첨탑 안쪽
  • 벽의 덩굴을 빛 모으기 또는 불화살로 제거 → 기어올라감
  • 옥상의 덩굴도 한 번 더 정리해야 조각까지 도달

④ 조립 — 여기서 대부분 막힘

  • 성소 중앙 빈 공간에 동력핵/조각을 올린 뒤, 그냥 F 상호작용이 아니라
  • 점프 → 공중에서 지정타(내리찍기) 로 박아 넣어야 결합됨
  • 위에서 아래 방향으로 내리찍는 각이 안 나오면 한 번 더 점프해서 재시도

⑤ 마지막 리듬게임 — 절대 스킵하지 말 것

  • 정화 마무리에 리듬게임 미니게임이 붙어 있음
  • 여기서 나오는 재료가 최종 티어 무기 · 스킬 붙은 방어구 · 편의 상점 제작에 쓰임

  • 성소 4곳 전부 이 보상이 있으니 매번 챙길 것

  • 성소 안에 보물상자 2개 있음 (같이 챙기기)

10-3. 나머지 성소 3곳 — 위치와 추천 순서

지혜의 마녀 성소 4곳은 전부 에르난드 권역에 있음. 정화할 때마다 성소 정화하기 (n/4) 카운트가 오름.

순서성소위치핵심 기믹난이도
✅금욕그레이스 영지, 유니콘의 절벽 남쪽동력핵 + 기둥 조각 2개보통
1회개금욕의 성소 바로 근처 (유니콘의 절벽 인근)2층 뻥 뚫린 공간에 기둥 조각 노출가장 쉬움
2축복에르난드 서쪽 — 지도의 'E' 글자 바로 아래1층 복도 안쪽 동력핵 + 횃불 점화로 비밀문 개방보통
3면죄스콜라스툴 남쪽보스 — 안툼브라의 검높음

추천 진행 순서: 회개 → 축복 → 면죄

  • 회개를 먼저 하는 이유: 금욕에서 걸어갈 수 있을 만큼 가깝고, 기둥 조각이 2층에 그냥 노출돼 있어 제일 빨리 끝남
  • 면죄는 반드시 마지막. 보스 안툼브라의 검은 "방어구 3강 이하면 한방 컷" 수준. 방어구 담금질 4강 이상 + 음식 넉넉히 갖추고 갈 것
  • 🔪 출발 전 숫돌(무기 데미지) · 모루(방어력)를 반드시 바를 것. 100대 때리거나 맞으면 풀리므로 보스방 직전에 (→ Q19-5)
  • 4곳 전부 정화하면 '지혜의 마녀' 퀘스트 클리어

다른 마녀 라인도 동일 구조 — 선함의 마녀(찬가·위안·구원·참회 / 페일룬), 겸손의 마녀(드메니스), 힘의 마녀(속죄·약조·계시 / 아세리안·타슈칼페). 해당 마녀를 만나야 그 라인 성소가 정화 가능.

Q11. 날아다니는 적 — 활 없이 잡기 / 화살 아끼기

상황: 공중 적(하피류·비행 마법사·유령 갑옷)에게 활만 쓰다가 화살이 순식간에 바닥남.

공식 가이드조차 "공중에 떠 있는 동안 순수 근접만으로 붙지 말 것" 이라고 경고. 하지만 활 말고도 길이 있다.

11-1. 최선 — 빛 모으기(Blinding Flash)

화살 0개로 공중 적을 즉사시킬 수 있는 유일한 수단.

순서조작
1Ctrl + 좌클릭 으로 검에 빛 모으기 발동
2시선을 공중 적에게 고정
3Ctrl을 계속 유지 — 충분히 오래 조준하면 즉사
  • 비행 마법사, 유령 갑옷 유닛에도 전부 통함
  • 안 먹히는 것 같으면 → 껐다가 다시 켜기, 그리고 거리 좁히기 (거리가 멀면 효율이 떨어짐)
  • 스토리 진행 단계에 따라 상위 버전(약점 포착)이 필요할 수 있음
11-2. 보조 수단
방법내용
급강하 타이밍대부분 공중 적은 내리꽂는 패턴이 있음. 공중에 헛스윙하지 말고 회피 → 착지·강하 순간에 몰아치기. 인내 싸움
집중 모드 밀어내기(unleash)스턴을 걸어 지상으로 떨굼
자연의 올가미 (Nature's Snare)적 투사체를 잡아 되돌려 보냄
자연의 응징 (Nature's Retribution)녹색 정령 스킬 트리. 대공 대응 기술
어비스 기어 유도 공격자동 추적이라 공중 적에게 잘 맞음
11-3. 그래도 활을 쓸 때 — 화살 아끼는 법
  • 정밀 사격(Focused Shot) 으로 한 발당 효율 올리기 — 난사 금지
  • 불화살은 따로 사지 말 것. 일반 화살을 횃불·화로 불꽃에 대면 그 자리에서 불화살이 됨 (→ Q2)
  • 일반 화살은 개당 동화 2개. 노점상·장비 상점·암시장 30곳 이상이 취급하니 마을 지날 때마다 100개 단위로 채우기
  • 장기적으론 마르지 않는 화살(어비스 기어, 1단계에서도 4% 확률) — 단 내구도가 있어 무한은 아님. 중요한 전투용으로 아껴 쓸 것

Q12. 야생 곰 — 갑툭튀에 죽지 않으려면 (대형 야수 전투)

상황: 필드 이동 중 곰이 갑자기 튀어나와 순삭당함.

12-1. 가장 먼저 — 싸울 필요 없으면 싸우지 말 것
  • 곰은 중립 야생 몹. 퀘스트 대상이 아니면 잡아도 얻는 게 적다
  • 말 호출(Z) 해서 올라타고 빠지면 추격을 뿌릴 수 있음
  • 이동 중이라면 굳이 상대하지 말고 거리 벌리는 게 이득
12-2. 죽는 진짜 원인은 체력이 아니라 스태미나
원칙내용
한계선스태미나 15% 를 절대 한계로 삼고, 그 아래면 전투 중단
0이 되면무방비 헐떡임 상태 → 대형 야수에게 걸리면 그대로 사망
회복 요령가드를 올리고 있으면 재생이 현저히 느려짐. 회복하려면 거리를 벌리고 가드를 완전히 내릴 것
공유 자원회피·가드·달리기가 전부 같은 스태미나 사용
12-3. 방어 — 패링과 회피

패링 (완벽 패링)

  • 스태미나 0 소모 + 들어오는 피해 100% 무효 + 적이 잠시 비틀거림
  • 타이밍: 적의 무기(곰은 앞발)가 앞으로 나오기 시작할 때 방어 버튼을 짧게 톡
  • 길게 누르고 있으면 그냥 가드 → 스태미나만 깎임

회피

  • 적의 몸통이 아니라 무기 든 손(앞발) 을 보고 타이밍을 잡을 것
  • 수평 휩쓸기는 스윙이 지나가는 방향으로 회피하면 피격 판정이 최소화됨

⚠️ 붉게 빛나는 공격 = 방어 불가. 이건 패링하면 즉시 넘어진다. 무조건 회피하거나 거리를 벌릴 것. 곰한테 죽는 대부분의 원인이 이걸 패링하려다 생김.

12-4. 반격 수단
수단효과
발차기 (Y)자세 무너뜨리기. 가드 깨기
빛 모으기 (LB+RB)일시 실명·스턴 → 딜 타임
등에 올라타기 + 지정타 연타곰이 멍해지며 행동이 둔해짐. 매달린 채 지정타를 계속 넣는 게 핵심
  • 곰은 후반에 특수 탑승물로도 활용 가능 → ⚠️ 정정: 곰·사자·물소·용 등 특수 탑승물은 전부 1회용이다. 내리면 야생동물로 돌아가 버리므로 구하려고 시간 쓰지 말 것 (→ Q19-16)

Q18. "어비스 빠른이동이 안 보인다" — 착각하기 쉬운 구조

✅ 정정 (인게임 확인): 순간 이동은 지상 지도에서 어비스 흔적 아이콘(노란 별)을 선택하면 화면 하단에 순간 이동 버튼이 뜨고, 누르면 바로 텔레포트된다. 메뉴 목록 형태가 아니라 지도에서 아이콘을 직접 골라 쓰는 방식이라 처음엔 안 보이는 것처럼 느껴진다.

18-0. 순간 이동 하는 법 (가장 실용적)
순서조작
1지도(전체 탭)를 연다
2지도의 노란 별 아이콘 = 어비스 흔적 을 커서로 선택
3하단에 [스틱] 순간 이동 이 뜨면 누른다 → 즉시 텔레포트
  • 순간 이동이 안 뜨는 흔적 = 아직 활성화 안 된 것. 직접 걸어가서 올라타야 목록에 들어온다
  • 목적지 근처의 흔적으로 점프 → 말 호출(Z) 로 마무리가 기본 루틴
18-1. 어비스 맵을 쓰는 또 다른 방법 (장거리)

어비스는 지상 위에 떠 있는 별도 공간이다. 이동 방식은:

  1. 지상의 활성화된 흔적/표석에서 어비스로 올라감
  2. 어비스 맵에서 목적지 방향의 섬·발판까지 이동
  3. 그 지점에서 아래로 낙하 → 활공해서 지상에 착지

즉 어비스 맵에 보이는 흰 동그라미들은 목적지 마커가 아니라 어비스 공간의 발판·섬이다. 이걸 "빠른이동 목록"으로 착각하기 쉽다.

커뮤니티 정석 운용: 먼 곳에 갈 일이 생기면 먼저 어비스 맵을 확인하고, 거리가 감당되면 어비스로 올라가 뛰어내린다. 지상으로 걷는 것보다 훨씬 빠르다.

18-2. 워프 지점 2종 — 활성화 방법이 다르다
종류생김새활성화
어비스의 흔적돌바닥 위 맨홀 모양올라타는 것만으로 활성화. 무료·즉시
어비스 표석큰 구조물근처 기믹을 해제하고 표석에 끼워진 어비스 아티팩트를 획득해야 활성화

💡 표석 = 아티팩트 획득처. 도전과제의 3단계(흔적 활성화 → 어비스 복구 → 아티팩트 획득)가 바로 이 구조다 (→ Q17). 표석 하나 풀면 빠른이동 지점 + 아티팩트를 동시에 얻는다.

18-3. 선택지가 없는 진짜 이유

현재 어비스 3/40. 올라갈 수 있는 지점 자체가 몇 곳뿐이라 "빠른이동이 안 보이는" 것처럼 느껴진다.목록이 고장 난 게 아니라 갈 곳을 아직 안 열어둔 상태.

  • 새 지역은 직접 걸어가서 흔적을 밟아야 목록에 생긴다
  • 흔적은 공짜다. 지나가는 길에 보이면 무조건 밟을 것
18-4. 빠른이동이 막히는 조건

  • 공중 · 낙하 중 · 말 탄 상태에서는 불가 → 내려서 실행

  • 쓸 만한 레전드 템끼리 비교하면 초기 상태 스탯 차이는 고작 1 정도
  • 인챈트(기어 추출·이식) 로 다른 무기의 기어를 다 옮길 수 있어서 특출나게 강한 템은 없다
  • 최종 무기는 디자인 취향으로 골라도 무방
💧 19-19. 폭포 속 보물 (13:46)
  • 안으로 들어갈 수 있는 폭포가 생각보다 많고, 들어가면 좋은 템을 루팅할 수 있다
  • 그냥 부딪히면 튕겨 나감 → 찌르기 스킬로 기를 모았다가 폭포를 향해 찔러야 진입 가능
🔬 19-20. 연구 기능 (14:50)

포로린 마을 · 듀웨이븐 마을 등에 연구소가 있다. 지역별로 연구 내용이 다름.

연구로 얻는 것

  • 현대화된 파밍 도구, 기능형 방어구 제조법
  • 캐릭터 최대 체력 증가
  • 다양한 버프 효과

조건: 특정 퀘스트 클리어 + 지식 축적 → 연구소를 연 뒤에는 그 지역 퀘스트도 같이 밀어줄 것

포로린 추천 아이템 — 그림자 위장복

  • 착용하면 야생동물이 도망가지 않는다 → 사냥·음식 수급이 훨씬 쉬워짐 (→ Q13)
  • 재료 2종: 포로린 마을 바로 앞에서 쉽게 구하는 것 + 최고급 목재

  • 듀웨이븐 지역 건물 재건 퀘스트(용병 파견)의 보상으로 약 10개 획득 가능
  • 10개면 위장복 중 신발 빼고 전부 제작 가능 (단, 신발이 빠지면 세트 효과가 안 남)
  • 더 구하려면 듀웨이븐 성채 연구소에서 전기톱 연구 필요 → 메인 퀘스트를 많이 진행해야 해금

💡 듀웨이븐 성채 경비병 통과 팁: 경비병들을 잡아 투구와 갑옷을 착용하면 적들이 아군으로 인식한다. 그래도 공격해오면 다른 지역으로 텔레포트해 시간을 끌고 돌아오면 더 이상 공격하지 않는다.

🧭 19-21. 진행 방향 (17:22)

  • 보스에 막히면 → 사이드 퀘스트·탐험으로 힘을 키우고 → 다시 메인 → 반복
  • 회색갈기 미션은 필수. 캠프가 발전하고 용병이 모인다 (→ 해오름의 터, 흩어진 불씨)

Q20. 방패 든 적 공략

문제: 약공격·강공격이 전부 방패에 막힌다. 10~20마리 무리에 섞여 있으면 한 마리씩 보스전 하듯 상대하게 된다.

20-1. 스킬 투자 없이 바로 쓰는 해법
수단조작효과
발차기Y (길게 누르면 드롭킥)가드 깨기의 기본. 자세를 무너뜨려 딜 타임 확보
잡기 / 던지기Y + B 또는 X + A방패를 무시하고 바로 잡는다. 커뮤니티 정석 — 수플렉스·바디슬램으로 처리
빛 모으기LB + RB일시 실명·스턴 → 방패가 내려감
등 뒤로 돌기회피로 파고드는 스킬방패 각도를 우회해 등을 친다

💡 무리 전투에서 가장 빠른 건 발차기로 자세 무너뜨리고 → 즉시 딜, 또는 잡기로 바로 던지기. 정면에서 약공격을 긁는 건 시간 낭비다.

20-2. 무기 세팅별
무기방패 상대
한손검 + 방패방패 강타가 가능 — 가드 버튼을 누른 채 강공격을 동시에, 타격이 들어갈 때까지 둘 다 유지. 가드 버튼은 가장 가까운 적을 자동 락온도 해준다
양손검담금질이 높으면 힘으로 방패째 밀어버린다. 담금질이 낮으면 비효율적
쌍검 / 양손무기방패 강타 불가 → 발차기·잡기 위주로 운용
20-3. 원거리로 우회
  • 구체 어비스 기어 — 어둠의 인도자 무기에 박혀 있는 기어. 우클릭으로 투사체 발사 → 방패를 무시하고 피해
  • 까마귀 공격 + 구체 조합이면 허공에 쳐도 딜이 들어가는 원거리 운용이 된다
20-4. 🎁 보너스 — 방패 강타로 봉인된 아티팩트 획득

도전과제 「변치 않는 의지의 방패 I」

순서내용
1헤르난드 타운 북쪽, 마구간(마굿간·안장 가게) 근처 제단에서 봉인된 어비스 아티팩트 획득
2일반 공격으로 적 체력을 깎는다
3마지막 일격을 방패 강타로 마무리
4총 3회 반복
5인벤토리의 빛나는 아티팩트를 사용 → 어비스 아티팩트 ×1 획득

⚠️ 절벽 근처에서 하지 말 것. 방패 강타로 날아간 적이 낙하 피해로 죽으면 카운트되지 않는다.

Q21. 4석상 회전판 고대 유적 퍼즐 (해맞이 평야 · 황금평야 등)

상황: 폐허 안에 석상 4개가 원형 판 위에 서 있고, 판 바닥에 빛나는 선이 그어져 있으며 가운데에 제단 기둥이 있다. 판을 돌려도 다른 판이 같이 돌아서 헤매게 되는 퍼즐.

21-1. 목표
  • 네 석상이 전부 가운데 제단 기둥을 바라보게 만들면 클리어.
  • 판 테두리의 삼각형 화살표가 정면(중앙)을 정확히 가리키면 그 석상은 정렬된 것. 바닥의 빛나는 선은 보조 힌트일 뿐이다.
21-2. 조작과 연동 규칙
항목내용
조작 위치석상 뒤쪽의 다이얼에서 상호작용
연동 규칙석상은 둘씩 짝으로 연동: 1번 다이얼 → 1·4번 석상이 함께 회전, 2번 다이얼 → 2·3번 석상이 함께 회전
한 틱다이얼을 돌리면 딸깍 멈춤 + 효과음이 나는 지점이 1단위
21-3. 정답 (해맞이 평야 기준 — 두 번 조작이면 끝)
  1. 1번 다이얼을 왼쪽으로 1/4바퀴 (딸깍 한 번).
  2. 2번 다이얼을 반 바퀴 (방향 무관).
  3. 네 석상의 삼각형이 전부 정면인지 확인. 어긋나면 해당 다이얼을 1틱씩 미세 조정.
21-4. 덩굴에 감긴 석상
  • 석상 하나(앞쪽 갈색 석상)가 덩굴에 감겨 있으면 그 다이얼은 조작 불가 → 빛 모으기(Q2 참고)로 덩굴을 태운 뒤 조작.
  • 황금평야(바이런 영지) 버전은 이 덩굴 석상이 단독으로 움직여서 오히려 에르난드 쪽보다 쉽다.

보상: 어비스 유물(아티팩트) + 유적이 빠른이동 지점으로 개방(그레이스 저택 근처 접근이 편해짐).

Q22. 둥지를 향하여 — 도약의 탑 작동시키기 (챕터 5 · 바이런 영지 왕의 산)

상황: 탑 정문 앞에 도착했는데 문이 열리지 않는다. 목표 "도약의 탑 작동시키기".

22-1. 입구 — 정문은 열리지 않는다
  • 정문(무너진 입구) 기준 오른쪽(남동쪽) 절벽 아래로 내려가면 숨겨진 동굴이 있다. 이 동굴이 탑 지하로 이어지는 유일한 입구.
22-2. 지하 — 바람 발판으로 최상층까지
  • 파란 바람 터빈 위에서 점프 → 점프 한 번 더(활공) 하면 바람이 위로 쏘아 올린다. 막히는 발판까지 올라가 최상층에 착지.
  • 부수면 안 되는 것: 지하 벽의 파란 구슬 2개(바람 동력원), 최상층 아래의 배터리 구슬(벽 패널 전원).
  • 엘리베이터 팁: 구슬을 빼면 엘리베이터가 내려오고, 다시 끼우면 올라간다 → 빼기 → 대기 → 장착 → 탑승.
22-3. 최상층 — 벽 패널 회로 잇기
조작내용
LB+RB (L1+R1) 길게벽 패널 안의 숨은 회로선 표시
L3 길게 (어비스 포스)패널 회전
  • 왼쪽 아래 패널부터 시작해 오른쪽 아래에서 끝나도록, 왼쪽 벽 입구 → 오른쪽 벽 출구로 전기가 흐르게 맞춘다.
  • 아래층에서 배터리(칩)를 강제로 뽑아 지정 위치에 다시 꽂는 단계 포함.
22-4. 중앙 원판 → 승천
  • 패널 완료 후 올라오는 발판에 서서, 파란 문양의 큰 원형 벽판을 2번(180도) 회전해 회로가 왼쪽-아래-오른쪽으로 이어지면 완료.
  • 발판에 계속 서 있으면 약 2분간 지붕이 열리며 하늘의 어비스(초승달 하늘길)까지 올라간다.
22-5. 하늘길(초승달 하늘길) 활성화 — 탑 정상에서 어비스로 올라간 뒤

기둥(장치)에 바로 손대도 전원이 없어 작동하지 않는다. 순서대로:

  1. 레이저 장치 3개 정렬: 어비스 시작점에서 오른쪽으로. 아래쪽 첫 장치는 이미 정렬됨. 위쪽 두 개는 공중 포스 팜(점프 후 손바닥)으로 띄워 올라가서, 장치 뒤쪽 작은 패널을 어비스 포스(L3 길게)로 잡고 2~3초 기다린 뒤 돌려 맞은편 주황 패널이 파랗게 변하게 맞춘다. 반대편도 동일.
  2. 건너가기: 중앙 레이저 장치 위에서 공중 포스 팜으로 최대 높이 → 활공해 맞은편 발판으로. (좌측 레이저 발판 경유도 가능)
  3. 끊어진 관(도관) 2개 연결 — 대부분 여기서 막힘.
  4. ① 건너가자마자 바로 앞 (중앙 파란 수정 뒤).
  5. ② 큰 원반(버튼) 오른쪽의 높은 단 위 (우측 수정 뒤 케이블 위). 단에 올라가서 연결.
  6. 가동: 관을 다 이으면 큰 원반에 불이 들어온다. 원반 중앙에 올라가 포스 팜으로 누르면 하늘길 작동. 장치 위에 올라가면 어비스 파편 획득. 이후 까마귀 부르는 자 추적 계속.

Q23. 거석 왕관 어비스 복구 (챕터 5 · 까마귀 둥지에서 하늘길 텔레포터로 진입)

퀘스트가 아님: 챕터 5 시점에는 메인/세력 의뢰 목록에 안 뜬다. 도전과제(어비스 x/40)에 포함되는 선택 어비스라 "복구하라" 문구만 표시됨. 메인 퀘스트로 묶이는 건 챕터 12 "심연 속의 그림자"(잠식된 칼리번 보스전 포함). 지금은 아티팩트 목적의 선택 사항.

상황: 까마귀 둥지(까마귀 부르는 자 보스전) 후 남서쪽 하늘길을 어비스 포스로 파랗게 만들어 텔레포터 진입 → "거석 왕관 어비스를 복구하라". 지도 왼쪽의 큰 원형 구조물이 퍼즐 방.

진행 결과 (2026-09-21): 까마귀 부르는 자 보스전 클리어. 도전과제 현황 — 탐험 5% (어비스 5/40 · 비경 1/60 · 고대 유적 3/37 · 성소 1/16 · 탑 2/8), 숙련 1% (한손검 1/6 · 활 0/6). 다음: 거석 왕관 어비스 복구.

23-0. 가는 길 (지상에서 직접 진입 불가)
  1. 초승달 하늘길 원반 가동 후 삼각형 아치를 지나 스위치를 어비스 포스로 파랗게(효과음) 될 때까지 돌리면 다리 개방 → 건너면 까마귀 둥지(까마귀 부르는 자 보스전).
  2. 보스 처치 후 까마귀 둥지 빠른이동 거점에서 앞으로 나무를 지나 오른쪽, 지역 남서쪽 모서리의 하늘길 장치를 어비스 포스로 파랗게 → 열리는 텔레포터 진입 = 거석 왕관.
  3. 보스 전에는 남서쪽 장치가 반응하지 않을 수 있음.
23-1. 퍼즐 구조
  • 떠 있는 큐브(우리) 안에서 레이저가 나온다. 큐브를 회전시켜 벽의 주황색 블록 전부에 레이저를 맞추면 클리어.
  • 큐브를 돌리면 안의 레이저가 중력 방향으로 떨어진다 → 한 번 돌리고 레이저가 내려앉을 때까지 기다린 뒤 다음 회전 (기본). 회전 순서가 중요.
23-2. 진행 순서
  1. 착지 후 공중 포스 팜 점프(점프 + R3) 3번 + 바람 터빈 활공으로 진행해 어비스 거점(빠른이동) 먼저 밟기. 여기서 수동 저장 (큐브가 꼬이면 로드가 빠름).
  2. 조종 장치: 오벨리스크 아래 북쪽(북서쪽) 발판의 스위치. 뒤쪽 왼쪽 구석 작은 떠 있는 섬으로 내려가 위를 보면 큐브 안 빛나는 링 → 어비스 포스(L3 길게)로 큐브 조종.
  3. 회전 순서 (PowerPyx): 위 → 대기 → 위 → 대기 → 위 → 대기 → 왼쪽 → 왼쪽 → 위(빠르게, 레이저 떨어지기 전) → 위
  4. 대안 (VULKK): 왼쪽 2번 → 아래 1번 → 카메라 180도 돌려 북쪽 보고 → 위 1번 → 아래 1번.
  5. 팁: 오른쪽 레이저 2개를 주황 블록 2개에 먼저 맞추면 나머지가 쉬워진다.
